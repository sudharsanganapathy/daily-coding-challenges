## 📖 About This Repository

Welcome to my **Daily Coding Challenges** repository!

This repository documents my daily journey of mastering **Data Structures & Algorithms (DSA)** and **JavaScript** through consistent practice.

My objective is to become a better problem solver, strengthen my JavaScript fundamentals, and prepare for **Frontend** and **MERN Stack** interviews by solving coding problems and learning core JavaScript concepts every day.

Instead of simply uploading solutions, every problem includes:

- 📝 Problem Statement
- 💡 Approach
- ⏱️ Time Complexity
- 💾 Space Complexity
- 🎯 Key Learning
- ✅ Clean & Readable JavaScript Code

This repository serves as both my coding journal and my interview revision guide.
